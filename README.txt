■ スマホでアプリとして使う手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【必要なファイル（全部同じフォルダに置く）】
  routine.html
  manifest.json
  sw.js
  icon-192.png
  icon-512.png

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【iPhone（Safari）の場合】

1. 上記ファイルをサーバーに置くか、
   Googleドライブ等でホスティングする
   ※ローカルファイル（file://）ではSWが動かないためHTTPS必須

   ▼ 一番簡単な方法：GitHub Pages（無料）
   ① GitHubでリポジトリ作成（無料アカウントでOK）
   ② ファイルをアップロード
   ③ Settings → Pages → Branch: main → Save
   ④ https://ユーザー名.github.io/リポジトリ名/routine.html にアクセス

2. SafariでURLを開く
3. 下部の「共有」ボタン →「ホーム画面に追加」
4. ホーム画面にアイコンが追加され、タップするとアプリとして起動

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Android（Chrome）の場合】

1. 同様にHTTPSのURLでアクセス
2. Chromeメニュー →「アプリをインストール」
   または「ホーム画面に追加」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【データについて】
・データはスマホのブラウザ（localStorage）に保存されます
・アプリを削除/ブラウザのデータを消去すると消えます
・機種変更時はlocalStorageのデータは引き継がれません
